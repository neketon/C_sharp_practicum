# C# Practicum

## Инструкция по запуску
1. Открыть решение в Visual Studio.
2. Собрать проект (`dotnet build`).
3. Запустить (`F5`).
4. Выбрать нужный уровень и номер задания в консольном меню.

## Статус заданий
| Уровень | Статус |
|---------|--------|
| Уровень 1 (1–15) | В работе |
| Уровень 2 (16–35) | Не начато |
| Уровень 3 (36–50) | Не начато |

## Заметки по Уровню 1
- Было сложно: разобраться с интерфейсом ITask и тем, как меню вызывает задания.
- Что узнал: как настраивать `.gitignore`, делать ветки и создавать Pull Request на GitHub.
